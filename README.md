# Free Pterodactyl Blueprints

Every Pterodactyl Blueprint extension I make is stored in the [blueprints](./blueprints) folder. Anyone is welcome to download, install, and use them completely free of charge.

## Why I'm doing this

I build these extensions for my own panel because I don't want to pay for premium ones. Since I'm making them anyway, there's no reason to keep them to myself. If they save someone else some money or time, that's a win.

## How to use them

1. Open the [blueprints](./blueprints) folder.
2. Download the `.blueprint` file for the extension you want. Click the file, then use the download button, or clone the whole repo.
3. Place it in your panel directory and install it the normal way with Blueprint:

   `blueprint -install extensionname`

## Check that they're safe

You should never install something on your panel without checking it first, and that goes for mine too. You don't have to take my word for it. Here are a few easy ways to verify any file:

- Scan it with [VirusTotal](https://www.virustotal.com)
- Run it through [Hybrid Analysis](https://www.hybrid-analysis.com)
- Scan it with [MetaDefender](https://metadefender.opswat.com)
- Paste the code into an AI assistant such as [Claude](https://claude.ai) or [ChatGPT](https://chatgpt.com) and ask it to look for anything malicious or suspicious

A `.blueprint` file is just a zipped archive of code, so you can also unzip it and read through everything yourself.
